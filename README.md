### A Systematic Study of Translation Effects on Multilingual LLM Evaluation

**Investigating how translation changes measured language understanding, with Bangla as the primary language alongside other South Asian languages and English.**

## Project objective

This project investigates when translation changes what multilingual LLM benchmarks measure. It distinguishes released English counterparts from actual machine translations and examines component effects, beneficial and harmful prediction changes, and model-ranking stability.

## Datasets

- **Belebele:** multilingual reading comprehension.
- **XNLI and Bengali IndicXNLI:** natural language inference.
- **TyDi QA—Bengali Gold Passage:** native Bangla question-answering validation.

## Models

Planned checkpoints, subject to pilot validation:

- **Qwen3-4B-Instruct-2507**
- **Gemma-3-4B-IT**
- **Llama-3.1-8B-Instruct**
